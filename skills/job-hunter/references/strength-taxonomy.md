# Strength Taxonomy

Use strengths as evidence-backed job signals, not personality labels.

## Strength Record Format

```text
### Strength: <能力名>
- Classification: fact | assumption | inference
- Evidence: <真实经历或材料>
- Behavior: <用户具体做了什么>
- Ability: <可迁移能力>
- Job signal: <对哪些岗位有价值>
- Confidence: high | medium | low
- Missing proof: <还缺什么证据>
```

## Ability Categories

| Category | Signals |
| --- | --- |
| 信息搜集与研究 | 能找到资料、比较来源、总结规律、做调研报告 |
| 结构化表达 | 能把混乱信息整理成文档、PPT、流程、表格 |
| 执行推进 | 能拆任务、跟进进度、协调资源、按时交付 |
| 数据与分析 | 会用表格、指标、实验、复盘解释问题 |
| 用户与市场理解 | 会观察用户反馈、评论、访谈、需求和痛点 |
| 内容与传播 | 会写作、剪辑、运营账号、组织活动、做增长 |
| 产品与流程意识 | 会画流程、拆需求、发现问题、优化体验 |
| 技术与工具使用 | 会编程、AI工具、自动化、数据处理、低代码 |
| 沟通协作 | 能对齐目标、推动他人、处理冲突、复盘合作 |
| 学习迁移 | 能快速掌握新工具、新领域，并产出作品 |

## Evidence Quality

- **High:** 有作品、链接、文件、截图、数据、第三方评价。
- **Medium:** 有具体行动和结果，但缺少外部证据。
- **Low:** 只有自我评价或模糊描述。

## Anti-Patterns

- Do not turn MBTI, 星座, 性格词, or "感觉适合" into career conclusions.
- Do not label the user as "不适合" a field without explaining missing evidence and possible proof-building actions.
- Do not overfit one weak experience into a permanent career direction.
